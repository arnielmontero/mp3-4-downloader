    How it works

    1. Type what you are looking for (or paste a YouTube link) and press Search.
    2. Pick MP3 (audio) or MP4 (video) on a result and press Download.
    3. The download appears in the Downloads sidebar with live progress. Start as many as you want; cancel any of them.
    4. When one is finished, press Download File to save it.

    MP3 files (192 kbps) are converted from the audio YouTube provides, so a higher bitrate cannot improve the original quality. MP4 uses the best available quality in a widely compatible format. Please only download content you are authorized to download.
