How it works

  1. Paste a YouTube video link and press Analyze.
  2. Choose MP4 (video) or MP3 (audio) and the quality.
  3. Press Download. You can cancel at any time.
  4. When it is finished, press Download File to save it.

MP3 files are converted from the audio YouTube provides; a higher MP3 bitrate cannot improve the original quality. Please only download content you are authorized to download.
